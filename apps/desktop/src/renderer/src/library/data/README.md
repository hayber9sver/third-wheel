# Parts catalogue data

Generated by `scripts/library/generate_catalogue.py`; do not edit by hand. Prettier ignores this folder.

| File             | What                                                                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `catalogue.json` | Modules, groups and classes of the library, search keywords, and for each class what its preview was built with (read by the panel). |
| `meshes.bin`     | The low-polygon preview meshes (layout described in `../mesh.ts`).                                                                    |
| `unbuildable.json` | Sizes the library lists in its tables but cannot build (e.g. ASME `#0-80` … `#2-64` screws raise `KeyError`); they are left out of the size choices. Each was tried with the preview's other values, so a size that fails here might work with other lengths. Not read by the app. |
| `report.json`    | Every class the generator tried: built, or why not. Not read by the app.                                                              |

**Provenance and licence.** The class list and the preview geometry come from
[bd_warehouse](https://github.com/gumyr/bd_warehouse) (Apache-2.0) running on
[build123d](https://github.com/gumyr/build123d) (Apache-2.0) and OpenCASCADE (LGPL-2.1). The preview
meshes are small approximations of the parts it generates, kept only so the panel can show a picture;
the real geometry is generated later by the user's AI. Regenerate when bd_warehouse changes and read
the diff of `report.json` and `catalogue.json`. The app's third-party licence list
(`apps/desktop/resources/THIRD_PARTY_NOTICES.txt`, built by `pnpm notices`) credits bd_warehouse and
build123d at the versions pinned in `scripts/library/requirements.txt`, with their licence and NOTICE
files from `scripts/licences/`.
